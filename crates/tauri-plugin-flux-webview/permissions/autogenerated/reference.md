## Default Permission

Lets the shell listen to the tab views' events (nav, scroll, back), open the system share sheet, pick folders through iOS, and take links shared to Flux. The tab commands stay Rust-only.

#### This default permission set includes the following:

- `allow-register-listener`
- `allow-remove-listener`
- `allow-share`
- `allow-pick-folder`
- `allow-folders`
- `allow-forget-folder`
- `allow-take-opened`
- `allow-set-chrome`
